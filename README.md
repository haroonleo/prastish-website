# Prastish Website V3

Premium single-page website for Prastish, ready for GitHub Pages.

## Upload to GitHub
Replace the files in your repository root with these files:

- `index.html`
- `styles.css`
- `script.js`
- `prastish-logo.png`
- `favicon.png`
- `apple-touch-icon.png`

Then wait 1–3 minutes for GitHub Pages to redeploy.
