# Prastish Website Starter

This is a free-hosting ready static website for Prastish.

## Files
- `index.html` — main website
- `styles.css` — visual styling
- `assets/prastish-logo.jpg` — logo image

## Free hosting options
Recommended:
1. Upload this folder to GitHub.
2. Deploy for free using Vercel, Netlify, Cloudflare Pages, or GitHub Pages.
3. Point `prastish.co.uk` DNS to the chosen free hosting provider.

You still need to keep paying the domain renewal fee for `prastish.co.uk`, but hosting can be free.
